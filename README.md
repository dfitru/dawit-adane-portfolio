# Dawit Adane Portfolio

This repository contains a static portfolio website for Dawit Adane, showcasing data engineering projects, services, mentoring offerings, and an AI demo section.

## Setup

Since this is a static site, no build step is required.

1. Clone the repository.
2. Open `index.html` directly in your browser.

## Deployment

The repository includes a GitHub Actions workflow (`.github/workflows/deploy.yml`) for deployment to GitHub Pages.
